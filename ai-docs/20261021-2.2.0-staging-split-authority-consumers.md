# 2.2.0（minor）：流式暂存区分库 `${appId}.${databaseId}.staging`；MSAL authority 默认 `/consumers`、`/common` 拒

> created 20261021 by Claude Fable 5.1 · as-of 2.2.0 · 道 6 F-58 §8 第 1 件（家族根 `ai-docs/20261021-idb-localstorage-inventory-and-split-proposal.md`；user 2026-10-21 16:50 对提案 A「同意」）+ 周账道 1 审计查出的 authority 默认值。**minor**：第一条真迁移 + 库布局变了；两处对消费者的接口面零变化。

## 1. staging 分库

- 以前：一等作品（`files/`）、回收站、备份箱、collections、流式暂存区（`staging/`）、SW 桥六个分区同库同表（`${appId}.${databaseId}` 一张 `blobs`）。暂存区是三等（re-fetchable 分片），和一等作品挤一张表，`usage()` 混在一起、配额压力互相拖。
- 现在：暂存区住自己的库 **`${appId}.${databaseId}.staging`**（`storeNamespace().stagingDbName`，钉字符串），一张 `blobs` 表，键形不变（`meta:<name>` / `chunk:<name>:<i>`）。仍在 `${appId}.` 前缀内 → `wipeAppNamespace` / `scanAppNamespace` 零改动自动覆盖（测试已加）。`databaseId` 不许以 `.staging` 结尾（撞库）。
- **迁移 = `MIGRATIONS` 第一条 `v001-20261021`**（ADR-0019 的体系第一次用上）：主库里的旧 `staging/` 键**不迁、整批删**（download-session 纪律：暂存区只装云端拉来的字节，清了绝不丢数据）。`MigrationCtx` 多一个可选 `blobs` 面（主库裸键 keys / del），createStore 跑迁移时开一条主库连接递进去、跑完关；测试 / 没 IDB 的环境没有这个面 → 那半跳过、照样盖戳。
- `dispose()` 关第四条连接（`stagingStore.close()` 本来就有，核过）。SW 网关（`stream/sw/gateway.ts`）自己按 `dbName` 开库——宿主注册 SW 时传的 `dbName` 要跟着改成 `.staging` 那个（KudsRocket 收包时看一眼 `createSwGateway` 的 dbName 参数；BR v2 暂停）。
- 消费方：只有 KudsRocket 真用暂存区；收包 = `pull-package.sh 2.2.0` + 跑快档，app 零改码（SW 网关 dbName 除外）。

## 2. MSAL authority 默认 `/consumers`

审计（周账 F-61 后续「store 之前拍的全审」）查出 `auth.ts` 的默认值还是 `/common`。家规 #7：personal Microsoft account only，authority 必须 `/consumers`，`/common` 禁止、无豁免。八个 app 都显式传了 `/consumers`，所以今天没炸——但库默认值不能是坑。现在：默认 `/consumers`；`configureOneDriveAuth({ authority })` 收到任何不是 `https://login.microsoftonline.com/consumers` 的值直接抛（`/common` / `/organizations` / 租户 id 都拒）。`authAuthority()` 给测试 / 诊断看。只对「不传 authority 或传错」的消费者有感 —— 家族里没有。

## 行为差异

- 暂存区的字节换库：升级后第一次开页，主库旧 `staging/` 键删掉、新库从空开始（下一次读盘重新拉，三等资源无损）。
- `storeNamespace()` 多返 `stagingDbName`；`MigrationCtx.blobs` 可选；`runStoreMigrations` 多一个可选参数。
- 515 测试（staging-split 三条 + maintenance 覆盖 `.staging` 库 + migration 注册表两条改口）。

## 没做

- Background Radio `dev/app.js` / `v2-spike/app.js`、JRP `ARCHIVE/config.js` 里还有 `/common` 字面量（老构建产物 / 归档，不在库仓）——记给 app 道。
