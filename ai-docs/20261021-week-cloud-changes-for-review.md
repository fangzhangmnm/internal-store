## 0. 先对几个词（下面全用白话，第一次出现就解释）

- **店库（store）** = 家族共用的云同步引擎：管「这份文件本机一份、云端一份，怎么对齐」。**图库（gallery）** = 家族共用的文件管理界面（列表、卡片、回收站），它只是前端，事实都问店库。
- **冲突面** = 店库弹出来问人的那张面：「本地覆盖云端 / 云端覆盖本地 / 取消」三选一。「面外方向动词」= 图库自己放的、不经这张面就决定方向的按钮（比如以前的「推送到云端」）。
- **回执** = 上传完云端回的那条「收到了、新版本号是 X」；回执丢了 = 字节其实传上去了但本机不知道。
- **If-Match / 谱系（血统）** = 推之前告诉云端「我是基于你第 N 版改的」；云端不是第 N 版就拒（412），店库再弹面。本机记着的那个 N 叫谱系；没谱系的推 = 「盲推」，店库一律不许。
- **dirty / 没传上去** = 本机有改动还没落到云端。**暂存区（staging）** = 流式读大文件（KudsRocket 的盘）时拉下来的分片缓存，可随时清、不是任何东西的正本。**镜像** = 盘的备用来源（你的 Tailscale 机器）。
- **等级表** = 2.1.0 起每种文件声明自己是几等：一等作品（冲突弹面、输家进备份箱）、二等自动备份（永不弹面、这台赢、输家不留底）、三等资源（只读，云端没了本机直接丢）。

## 3. 你说要重新讨论的两条（原话）

① **「冲突只在库的面里三选一、app 不带方向动词」这条设计**。10-16 你定的是「我要的就是本地覆盖云端和云端覆盖本地二选一啊！这个才是安全的模型！」「取消也要」「禁止越狱」；它推到图库上变成了「只剩『处理…』、所有方向动词进库的面」（第 2、5、6、20 条）。10-21 你说：**「面外方向动词拿掉其实这个设计不一定好，记账有空好好讨论」**；审计问到的四个动词（拉取到本地 / 卸载本地 / 留一份离线 / 送到回收站）你说「留着」。现状：这条线冻结——不再往里加刀、也不退，等你开一次讨论。**「登录后问一次再推」（第 21 条）也挂在这条下面**：你 10-21 对统筹「问一次这个大方向同意，但是……无方向这个1016设计其实我没好好想过，可以讨论」——讨论的结果会连它一起定。可能要想的：哪些动作其实不是「冲突」只是「取副本 / 放副本」，该不该也绕面；「处理…」这三个字够不够说清楚。

② **「行为变更默认开」要先写清为什么**。10-15 你定的库政策是「行为变更默认关、消费方显式开」（0.17.2 把三个传输开关都改回默认关）；0.18.0 的「干净副本接谱系」（第 3 条）却是默认开，当时没写为什么不走默认关。10-21 你追认「默认开，下次遇到同样的问题还是需要想清楚」。现状：出处已补进 0.18.0 发版说明；规矩 = 以后库要默认开任何行为变更，发版说明里先写「为什么这条不走默认关」。
