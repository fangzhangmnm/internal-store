# 2.2.5（patch）：「处理…」比字节那一趟也有逃生口

> created 20261104 by Claude Fable 5.1 · as-of 2.2.5 · user 11-04「4 做」（Fable 自审 #3，周账 F-185）· 数据安全模型 A19「每个等云端的时刻都有出口」

## 1. 改了什么（一处）

`create-store.ts` `file.resolve()`：2.2.3 加的「弹面前先拉云端逐字节比」那一趟，现在和宿主的 `ui.offlineEscape()` 的 probe 赛跑（open 路 2.2.2 早就这样）。probe 先到（人点了「跳过到离线」）→ 返 `{ status: "offline" }`，不弹面、不改任何状态；比字节先到 → 照 2.2.3。宿主没接 offlineEscape → 和 2.2.4 一样（等传输层超时）。

## 2. 行为差异

| 场景 | 2.2.4 | 2.2.5 |
|---|---|---|
| 「处理…」时云端挂死、人点「跳过到离线」 | 等到传输层超时才回 | 立刻返 offline，零面，仍脏 |
| 其余 | 不变 | 不变 |

`test/resolve-heal.test.ts` 加一条：probe 先到 → offline、零面、不卡、仍脏。整库 540 过。（上一个 2.2.5 = `only` 谓词已撤回、没推过，版本号复用。）
