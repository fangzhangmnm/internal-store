# 0.18.0：open 核对没跑成时干净副本接血统（默认开，可关）+ `file.resolve()` 主动叫冲突面

> created 20261016 by Claude Fable 5.1 · as-of 0.18.0 · user 2026-10-16「库 bump minor 做」「我要的就是本地覆盖云端和云端覆盖本地二选一啊！这个才是安全的模型！」「取消也要」「禁止越狱」；WXHW 会话 10-16 查出的单设备根因（`20260516 WebXiaoHeiWu/ai-docs/20261008-store-0162-signin-push-order-handoff.md` §6.1）。minor（新接口 + 一条默认行为变化）。

## 行为差异（和 0.17.2 比）

| 项 | 0.17.2 | 0.18.0 默认 | 关掉 |
|---|---|---|---|
| open 时云端核对没跑成（离线 / 未登录 / fetchMeta 抛错 / 用户 probe 跳过），本地副本**干净**且磁盘上有上次同步的 etag | 什么都不记 → 本 tab 无 base → 之后第一次 save 的推不带 If-Match → `conflictBehavior:"fail"` → 云端有同名 → 409 → 大小不等 → `CloudNameCollisionError` → 冲突面（云端其实没人动） | **把那个 etag 记为本 tab 的 base**（`head.markSeen`）→ 第一次推带 If-Match：云端没动 → 成功；动过 → 412 → tryHeal / 冲突面（和以前一样） | `createStore({ openLineageFromDurable: false })` |

安全边界：base 只会被记成**本地字节当时同步到的那一版**（durable etag 只在 push 成功 / markSynced 时和字节一起写），永远不会比字节更新 → If-Match 照样挡住真分叉。脏副本一律不动（脏的 parent 只能由 recordEdit 或云端确认过的 markSeen 给；从 durable 补 parent 在多标签页下会变成静默覆盖——**没做，也别做**）。seenBase 的其他消费者（offload 守卫、upload-queue、reconcile、safe-resolve 备份判据、uploadReplay.enqueue）本来就回退到同一个 durable etag，行为不变。

## 新接口

`RawFile.resolve(opts?: { adopt? }): Promise<ResolveOutcome>`——库**自己**弹 `ui.resolveConflict({ occasion: "push" })`，按人选的走既有派发：本地覆盖云端 = 正常 If-Match 推（云端此刻若已变 → 412 → 库再弹面，不预设答案）；云端覆盖本地 = `safePull({ forceBackup: true })`；取消 = 不动。干净的文件返 `clean`。app 只负责调它、**不传答案**。
`ResolveOutcome` = no-local / clean / offline / cancelled / pushed / not-pushed(reason) / took-cloud(backupName) / unresolved(reason)。took-cloud 后 app 必须整份重读。

被否决的替代方案（别再提）：`file.takeCloud()`（app 代码不经面就换字节——哪怕先进备份箱也是越狱）；app 侧预设答案喂 `resolveConflict`（KudsRocket v0.1.33–0.1.35 的 presetResolution，已删）。

## 0.18.1（同日，patch）：`RefreshOpts.trustHints`

WXHW 收 0.18.0 后全套 e2e 翻红一条：「挂机：别的设备改过、这台干净 → 醒来静默快进」——0.17.0 的 fresh-hints（30 s 内的完整清单帧说 etag 没变就跳过 fetchMeta）把醒来那次核对顶掉了：别的设备恰好在这 30 s 里推过。这是 fresh-hints 当初写明的 TOCTOU 窗口，但「醒来 / 回前台 / 刚登录」正是 app **怀疑自己过期**的时刻，不该省这一趟。
加 `pullIfClean({ trustHints: false })`（默认 true = 0.18.0 行为）：这次一定问云端。消费方在挂机醒来 / 回前台 / 登录后的刷新里传 false；连着 open 几十个小文件的场景保持默认。测试 `test/open-lineage.test.ts` 末条。
