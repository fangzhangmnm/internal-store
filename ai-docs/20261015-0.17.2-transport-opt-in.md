# 0.17.2：0.17.1 的传输层行为全部改成显式开关，默认回到 0.17.0

> created 20261015 by Claude Fable 5.1 · as-of 0.17.2 · user 2026-10-15「是否需要store分家……我其实非常怕把家族文件的那些app开始丢画」→ 三条政策「123同意」（本仓 CLAUDE.md）。patch。

## 行为差异（和 0.17.1 比）

| 开关 | 0.17.1（默认开） | 0.17.2 默认 | 显式开 |
|---|---|---|---|
| Graph 请求超时 | meta 30 s / chunk 120 s / range 60 s / blob 15 min | **无超时（= 0.17.0）** | `createOneDriveProvider({ transport: { timeouts: DEFAULT_GRAPH_TIMEOUTS } })` |
| 分块上传单块失败接着传 | 开 | **关（单块失败 = 整份网络错，交上层重试 = 0.17.0）** | `transport: { chunkResume: true }` |
| 提交最后一块前核 eTag | 开 | **关（只在开会话时核 = 0.17.0）** | `transport: { verifyChunkedCommit: true }` |
| push 重试退避 | 5 次 1/2/4/8 s | **4 次 × 200·n ms（= 0.17.0）** | `createStore({ pushRetry: { maxAttempts: 5, backoffMs: 1000, exponential: true } })` |

和 0.17.0 比：**没有行为差异**；只多了上面四个开关、`GraphTransportOptions` / `GraphTimeouts` 类型和 `DEFAULT_GRAPH_TIMEOUTS` 常量的导出、`StoreConfig.pushRetry`。

## 谁开了

KudsRocket v0.1.29 起四个全开（它报的案：iOS 锁屏后 fetch 永远挂着、网络抖一下整份重传）。艺术类 app（WeebPaint / WXHW / CatsUp / JRB）不开——它们升级时按上表逐条决定。
